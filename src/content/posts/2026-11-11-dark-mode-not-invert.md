做深色模式最省事的办法，是把颜色变量取个反：白底变黑底，黑字变白字。能看，但很难看。因为浅色下那些让界面立起来的光影，在深色下会全部露馅。

## 高光要收敛

浅色纸张的顶部高光是 72% 的白，在白纸上是自然的受光。原样搬到深色纸面上，就成了一条醒目的白带，看起来像盖了层半透明蒙版。深色下我把它降到 5% 左右，阴影改成更黑、更局部：

```css
:root.dark {
  --contact: rgb(0 0 0 / 0.55);
  --ambient: rgb(0 0 0 / 0.30);
}
```

亮边从白色描边变成极弱的环境反射。它还在，但你不会注意到它，这正是高级暗色界面该有的样子。

## 阴影要更黑更局部

浅色下靠灰色阴影和背景拉开层次。深色背景本身就接近黑，灰色阴影完全看不见。所以深色阴影必须更黑（接触阴影用 55% 黑，环境阴影 30%），而且更近：把模糊半径压小，靠多层叠加代替一层大模糊。一个软绵绵的大投影在深色里会变成一团脏，两三层紧实的阴影才会让物件坐在桌面上。

## 深色里的纸不是黑

这是最容易忽略的一点。如果桌面是 `#0b0e13`，纸张用纯黑 `#000`，纸反而比桌面更暗，看起来像个洞。深色纸张应该是带一点蓝的深色板岩：

```css
:root.dark {
  --desk: #101114;
  --paper-stock: #171d25;
  --enamel: #1e252e;
  --metal-mid: #262e38;
}
```

桌面最暗，纸张比桌面亮一档，珐琅再亮一点，金属最亮。材质之间的明度关系和浅色主题是一致的，只是整体下移了一个色阶。

## 边框和分隔线

浅色下的发丝线用 10% 的黑，深色下不能简单反过来用白色 10%，会显得到处都是亮线。深色下边框分两种：物体边缘用 7% 的白，几乎看不见；切割凹槽用 50% 的黑，靠暗部来定义。也就是说，深色界面里凸起靠微弱的反射，凹陷靠明确的暗边，这个逻辑和浅色正好相反。

## 光斑也别用蓝色

我最初在深色桌面加了一个偏蓝的光池，看起来像科幻界面。改成中性灰白之后才对。深色主题的高级感来自克制，不是来自冷色调。

## 验证方式

不要只看某一页。我把首页、文章页、归档、工具页、移动菜单、四个浮层全都在深浅两套主题下截图对比。很多时候一个变量改了，浅色没事，深色的某个面板就出现亮带或者文字消失。

深色模式不是反色，是重新设计一遍光影关系。变量结构可以复用，但每一个数值都要重新判断。
