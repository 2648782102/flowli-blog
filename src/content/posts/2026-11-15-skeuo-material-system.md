这个博客的视觉改了很多轮。有一版我用的是教科书式的拟物配方：圆角、上浅下深的渐变、一圈白色内描边、再加一层灰色的柔和投影。每一条单拿出来都没错，拼在一起却像一堆贴纸，所有卡片长得一模一样，页面像是一个模子刻出来的。

后来我意识到问题出在哪：**我没有在描述材质，我只是在描述阴影。**

## 贴纸感和真实感的分界线

真实世界里的东西，即使摆在一起，也不会共用同一套表面处理。纸是哑光的、有纤维；金属是冷的、有拉丝方向；珐琅是光滑的、有一道窄高光；桌面是硬的、有织纹。它们在同一个光源下，会呈现完全不同的边缘和阴影。

而我之前的代码是这样的：

```css
.card {
  background: linear-gradient(180deg, #fff, #eee);
  box-shadow:
    0 1px 0 #fff inset,
    0 -1px 0 #0002 inset,
    0 8px 20px #0002;
}
```

每一个卡片都是这段。于是文章、按钮、导航、侧栏全都成了同一种塑料片。

重做的第一步不是调参数，而是**建立材质词汇表**。我先定义了五种材质：桌面（承载物）、纸张（阅读面）、金属（导航导轨）、珐琅（控件）、凹槽（数据窗）。每种材质只描述四件事：底色、光源、边缘、接触阴影。

## 单一光源比多层阴影更重要

高级感很大程度来自一致性。我固定了一个来自左上方的光源，所有材质的高光只出现在受光侧：

```css
:root {
  --lit-angle: 145deg;
  --rim-strong: rgb(255 255 255 / 0.92);
  --contact: rgb(38 30 18 / 0.20);
  --ambient: rgb(38 30 18 / 0.08);
}
```

关键是**亮边只画受光的一侧**，不再给四个边都加白线。深度靠两层阴影：一层紧贴物体的深色接触阴影，一层很淡很远的环境阴影。单个模糊阴影看起来是悬浮，接触阴影加环境阴影看起来才是放在桌上。

## 明度差要足够大

一开始我把桌面设成 `#eae6dc`，纸张设成 `#fbf8f1`。截图放大看几乎分不出来，纸张像印在桌面上。后来我把桌面压到 `#dcd8ce`，纸张提到 `#fdfbf5`，大概 8% 到 10% 的明度差，层次才真正成立。

这是一个很反直觉的点：为了显得精致，我最初把对比度压得很低，结果反而显得平。适度拉开明度，材质才读得出来。

## 纸的颗粒：细到几乎看不见

纸张我用了内联 SVG 的分形噪声做纹理。第一版颗粒强度设成 0.55，放大看像砂纸。降到 0.16 之后，正常阅读距离几乎看不到，凑近才有一点纤维感，这才对。纹理的作用是让眼睛觉得这是实物，不是让人看见纹理本身。

重复的 1px 线性渐变做纹理在 100% 缩放下会变成纱窗纹，很假。分形噪声比它自然得多。

## 深色模式不是反色

深色主题最容易翻车的地方，是把浅色那套高光原样搬过来。浅色纸张顶部那道高光，在深色下会变成一条明显的白带，看起来像盖了层半透明蒙版。深色下我把它压到 0.055，阴影改成更黑、更局部：

```css
html:root.dark {
  --contact: rgb(0 0 0 / 0.55);
  --ambient: rgb(0 0 0 / 0.30);
}
```

深色里的纸不是纯黑，是带一点蓝的深色板岩；亮边变成极弱的环境反射。这样纸张才能从桌面上浮起来，而不是融进背景。

## 最后

拟物不是加很多阴影，是给页面里的每个物件一个它是什么的答案。当桌面、纸张、金属、珐琅各司其职，光源和阴影规则统一，页面自然就贵了。反之，再精细的渐变也只是在给贴纸抛光。

这次改造的代码都在 `src/styles/skeuo.css` 和 `src/styles/skeuo-materials.css`：前者定义材质，后者决定每个元素用什么材质。分开之后，改一个材质的质感，全站一起变，不用逐个组件调参数。
