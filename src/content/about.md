# 关于我

你好，我是 flowli。

一个前端开发出身、现在依然喜欢动手做东西的人。这里记录我在技术、工具和日常生活中的实践与想法。

## 关于这个博客

这个博客从 2026 年 11 月开始搭建。技术上是 Astro 5 + Svelte 5 + Tailwind 4，静态生成，托管在 GitHub Pages，整个仓库是公开的。它既是一个写作的地方，也是我自己折腾前端的一个试验场。

如果你对它的实现感兴趣，可以直接看代码：[flowli-blog](https://github.com/2648782102/flowli-blog)。

## 我会写什么

- **前端工程**：CSS 布局、视觉设计、构建工具，以及那些看起来很小但很折磨人的 bug。
- **工具与实践**：我正在用的编辑器、命令行工具、开发流程，不追新，只写真正留下来的。
