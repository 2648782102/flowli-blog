# Reference Board — 编辑型技术写作

日期：2026-11-11（Asia/Shanghai）

截图采集方式：Chrome headless，桌面 `1440×900`，全页截图，light scheme。文件位于 `design/screenshots/references/`。参考只用于抽取原则，不复制品牌、文案、图片、专有布局或代码。

## 01 — Maggie Appleton / Home

来源：<https://maggieappleton.com/>  
截图：`01-maggie-appleton-home.png`

- Steal：超大但不过度装饰的衬线/显示标题；首页直接说明作者写什么；内容按「Essays / Notes / Patterns / Library」分组，而不是把所有东西做成同款卡片。
- Steal：大量纸面留白、细分隔线、克制的强调色；图片/封面服务于文章识别，不做装饰性渐变。
- Avoid：完整照搬「数字花园」分组结构、插画、个人品牌符号。

## 02 — Josh W. Comeau / Blog index

来源：<https://www.joshwcomeau.com/blog/>  
截图：`02-josh-comeau-blog.png`

- Steal：浅冰蓝背景、清晰的分类标题、两列文章索引、每篇文章以标题 + 摘要 + 明确「Read more」形成扫描节奏。
- Steal：卡片用高不透明度纸面和单一轻阴影，正文可读；底部可有个性化图形，但不干扰文章区。
- Avoid：全站同款大圆角白卡、波浪背景、插画式品牌装饰、emoji 语气。

## 03 — Jim Nielsen / Blog home

来源：<https://blog.jim-nielsen.com/>  
截图：`03-jim-nielsen-blog.png`

- Steal：极致文本优先；标题、短介绍、文章列表、日期、归档链接；导航收束到右上角少数图标。
- Steal：单一强调色只用于链接和关键动作，空白本身就是布局。
- Avoid：照搬红色强调色；本项目仍保留藏蓝主色。

## 04 — swyx / Home

来源：<https://swyx.io/>  
截图：`04-swyx-home.png`

- Steal：杂志式首页信息架构：一句个人定位、少量核心长文、项目/写作/演讲/最近条目分区，用横向细线建立秩序。
- Steal：暖纸色背景 + 单一深红/棕强调，证明「不靠玻璃也能有质感」；长列表用日期和元数据构成节奏。
- Avoid：复杂多栏、个人品牌插画、订阅表单、播客/项目等过度内容堆叠。

## 05 — swyx / Ideas index

来源：<https://swyx.io/ideas>  
截图：`05-swyx-ideas.png`

- Steal：归档/索引页采用密集但可扫描的表格行：日期、标题、类型、阅读时长；顶部少量精选，下面是全量记录。
- Steal：筛选与排序是功能性控件，不做发光或玻璃装饰。
- Avoid：把每篇文章都包成卡片；本项目归档页应更安静。

## 06 — Jim Nielsen / Archive

来源：<https://blog.jim-nielsen.com/archive/>  
截图：`06-jim-nielsen-archive.png`

- Steal：归档就是纯列表，按年份分组，不靠封面图或卡片提高「设计感」。
- Steal：极长的全量列表仍保持一致的基线网格和链接状态。
- Avoid：直接复制站点的极简白色/红色；本项目需要藏蓝与少量玻璃作为身份线索。

## 提炼出的共同原则

1. 首页先告诉读者「这里是谁、写什么」，再展示内容；不要先展示壁纸和装饰。
2. 正文与文章索引使用稳定纸面；材质只服务功能层。
3. 强调色极少，主要用于链接、选中态、关键动作。
4. 列表/归档是文字与日期的节奏，不是卡片网格。
5. 字体、留白、分隔线承担了大部分视觉质量；阴影、圆角、渐变只是辅助。
6. 参考图是评审标尺：后续原型必须与这些图并排比较，而不是凭文字说「高级」。
