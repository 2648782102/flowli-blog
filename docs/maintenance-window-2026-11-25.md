## 本轮完成

- 修好分类链接 `<a>` 包 `<button>` 的非法嵌套；分类项现在是单一 `<a>`，包含文字与数字读数。
- 修复一次 CSS 选择器误写：原本把侧栏所有链接都当成 `.rail-row::after` 规则，导致分类内容被隐藏；已恢复并保持视觉零回归。
- 分类 hover 改为索引式：无填充块、无左侧色条，仅文字变深与行尾细线；数字保持次级色。
- 补手型：`a[href]` 与按钮均为 `cursor: pointer`，解决 Tailwind preflight 把按钮设为 `default` 的问题。
- 补 `:focus-visible`，键盘 Tab 到分类时有清晰焦点圈。
- 非首页切页时，侧栏不再带 `transition-swup-fade`；内部 widget 不淡出、不位移。
