# 视觉收敛：2026-11-24

目标模式：**一个材质系统、一个强调色、三档字重、低权重侧栏、页面专属内容只做组合不另造语言**。

这轮不重做拟物系统。纸、搪瓷、金属、凹槽仍然只有一套定义；改变的是各处如何调用它。

## 已收敛

- **字重**：全站只用 500 / 600 / 700。原先的 620 / 650 会让本地字体走匹配或合成路径，标题粗细不可控。
- **颜色**：项目页、技能页、时间线页的蓝色渐变统计块、蓝色进度条、黑白 Tailwind 文本，统一换成 `tool-stat`、`tool-chip`、`tool-progress`、`tool-link` 等语义类；这些类只引用 token。
- **金属头部**：由冷灰铝改为暖灰金属，和暖纸桌面同源；仍是细拉丝 + 单一上光源，不改材质结构。
- **首页诗句**：尺寸 3.4rem → 2.8rem，墨色占比亮色 58% → 48%、暗色 44% → 38%。保留竖排个性，但从“第二标题”退回墙面装饰。
- **侧栏资料卡**：头像缩小，名字和简介降级；侧栏不再和正文争主次。
- **项目展示图**：重截当前首页，移除旧版挂画截图；项目页不再展示已经不存在的视觉。
